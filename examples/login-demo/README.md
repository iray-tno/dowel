# login-demo

Phase 0 benchmark app. Exercises `@dowel/core` primitives (`View`, `Text`, `Pressable`, `Button`), a Tailwind subset (flex, spacing, color, typography), and conditional `className` through the Vite + Dowel compiler pipeline.

```
pnpm install
pnpm --filter @dowel/compiler build:native
pnpm --filter login-demo dev
```
