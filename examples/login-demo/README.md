# login-demo

Phase 0 benchmark app. Exercises `@hozo/core` primitives (`View`, `Text`, `Pressable`, `Button`), a Tailwind subset (flex, spacing, color, typography), and conditional `className` through the Vite + Hozo compiler pipeline.

```
pnpm install
pnpm --filter @hozo/compiler build:native
pnpm --filter login-demo dev
```
